\title{When does an LLM autoresearch loop find real signal?\\
\large A controlled study on twelve biomedical prediction tasks}
\author{\todo{Author Name}\\ \todo{Affiliation}\\ \texttt{\todo{email}}}
\date{}

\begin{document}
\maketitle

\begin{abstract}
Autoresearch loops, in which a large language model (LLM) repeatedly rewrites a single solution
file and a change is kept only if a fixed development score improves, are an increasingly common
way to build predictive pipelines. We ask when such a loop finds signal that holds up on held-out
and external data. We ran a loop driven by Claude Opus 5.5 on 12 biomedical prediction tasks
(scalp and neonatal EEG, resting-state fMRI, 16S microbiome, proteomics and drug response;
3 splits per task, 20 rounds per loop). Each champion was scored once on a held-out 25\% of subjects
and on eight external datasets, and compared with three baselines given the same 20 development
evaluations: one LLM proposal, 20 independent LLM proposals without feedback, and Optuna search over
a pipeline written with knowledge of the loop's findings. Development scores improved in all 36 runs;
held-out scores in 25. Averaged over 11 AUROC tasks the loop gained $+0.050$ AUROC over the seed
(95\% CI $+0.006$ to $+0.094$), compared with $+0.004$ for one proposal, $+0.014$ for 20 proposals
without feedback and $+0.033$ for Optuna. The pooled gain was not robust to removing any one of
six tasks, and the loop's advantage over Optuna ($+0.017$, $p=0.28$) was significant only for
abnormal-EEG and neonatal-seizure detection, the two tasks whose gains also replicated across
independent repeats of the loop. When site and demographics were available, the loop built its
models on them, and its gains on psychiatric EEG did not transfer to external cohorts. Feedback is
what makes the LLM useful here, but the loop does not replace shortcut-free scoring and external
validation.
\end{abstract}

\section{Introduction}\label{sec:intro}
% ===========================================================================================
LLM agents can now write, run and revise machine-learning code with little supervision
\citep{huang2024mlagentbench,chan2024mlebench,jiang2025aide,lu2024aiscientist}. The simplest
version is the \emph{autoresearch loop} \citep{karpathy_autoresearch,autoepi}: one editable file,
one fixed metric, and a model that proposes a change each round, kept only if the metric improves.
On development data the loop always looks like it works, because a keep-if-better rule over a
fixed cross-validation (CV) score cannot make that score go down.

Biomedical prediction is a hard test of whether such gains are real. Datasets are small, cases
and controls are often recruited and recorded differently, and site, scanner, batch and
demographics can predict the label better than the biology
\citep{zech2018confounding,geirhos2020shortcut,varoquaux2022failures}. Leakage and shortcuts are
already common in human-written studies \citep{kapoor2023leakage,racz2025szleakage}, and selecting
the best of many candidates on one CV score is itself a source of optimistic bias
\citep{cawley2010overfitting}. An optimizer that tries many ideas against one score has every
opportunity to find all of these.

We therefore ask not whether the loop improves the development score, but \emph{when} the
improvement holds up: on held-out subjects, on external cohorts, against simpler uses of the same
budget, and under checks for confounding and leakage. Across 12 tasks in six domains under one fixed
protocol, we contribute
(i)~held-out results for 36 loop runs, each scored once, plus independent repeats on 9 tasks;
(ii)~three same-budget baselines that separate the effect of feedback from that of the LLM and
of ordinary search;
(iii)~multiplicity-corrected per-task statistics that include split and run variation, and pooled
estimates with sensitivity analyses;
(iv)~evidence that the loop exploits site and demographic shortcuts when they are available, and
an age/sex confound analysis of the shortcut-free results; and
(v)~transfer to eight external datasets, a transduction audit and a leakage audit.

% ===========================================================================================
\section{Related work}\label{sec:related}
% ===========================================================================================
Benchmarks such as MLAgentBench \citep{huang2024mlagentbench} and MLE-bench \citep{chan2024mlebench}
evaluate agents that write and run training code; AIDE \citep{jiang2025aide} searches code with
tree-structured refinement; the AI Scientist \citep{lu2024aiscientist} automates the wider research
cycle; and FunSearch \citep{romeraparedes2024funsearch} and AlphaEvolve \citep{novikov2025alphaevolve}
pair LLM proposals with an automatic evaluator. Most of this work reports scores on the benchmark
the agent optimized. The autoresearch loop \citep{karpathy_autoresearch} is a deliberately minimal
member of this family, and our protocol reuses that of \citet{autoepi}. As a non-LLM reference we
use tree-structured Parzen estimators \citep{bergstra2011tpe} in Optuna \citep{akiba2019optuna}.
Our focus is a controlled evaluation in a domain where selection bias \citep{cawley2010overfitting},
leakage \citep{kapoor2023leakage} and site or demographic shortcuts
\citep{zech2018confounding,brown2012adhd200} are well documented.

\section{Methods}\label{sec:methods}
% ===========================================================================================

\paragraph{Loop.} A fixed harness loads the data and defines labels, splits and metric; it is never
shown to or edited by the LLM. A solution is one Python file implementing
\texttt{featurize(items, ctx)}, which never receives labels, and
\texttt{fit\_predict(F\_train, y\_train, F\_test, ctx)}, which receives training labels only. Each
round the LLM (Claude Opus 5.5, reasoning effort \emph{high}) receives a general brief, a project
brief, the current best solution and the full history of previous rounds (rationale, declared
feature/model families, score, kept or not, last failure), and returns a complete new solution.
Candidates run on CPU containers with a 1{,}500\,s limit (timeouts and crashes count as failed
rounds). A loop runs 20 rounds with patience 10 and keeps a candidate iff its development score
improves by more than $10^{-4}$.

\paragraph{Tasks.} \Cref{tab:tasks} lists the 12 tasks: abnormal EEG (TUAB \citep{obeid2016tuh});
depression and ADHD (TDBRAIN \citep{vandijk2022tdbrain}; the two tasks share 90 controls);
schizophrenia (ASEEG \citep{aseeg}); per-second neonatal seizure detection (Helsinki
\citep{stevenson2019helsinki}); autism and ADHD from fMRI connectivity (ABIDE I
\citep{dimartino2014abide}, ADHD-200; \citep{pcp}); colorectal cancer (CRC) and IBD from 16S stool
profiles (MicrobiomeHD \citep{duvallet2017,baxter2016}); Alzheimer's disease (AD) from plasma
\citep{pxd065835} and CSF \citep{bader2020} proteomics; and drug response from CCLE expression to
PRISM AUC \citep{corsello2020,depmap24q4}. Seeds were written before any loop ran and are
deliberately standard: log band power with L2 logistic regression (scalp EEG); line length, RMS and
band power with gradient boosting and smoothing (neonatal EEG); Fisher-$z$ CC200 connectivity with
logistic regression (fMRI); genus abundance with a random forest (16S); log$_2$, median centring and
logistic regression (proteomics); and ridge regression on the most variable genes (drug response).

\paragraph{Shortcut-free protocol (v2).} Our first protocol (v1) passed age, sex, head motion and
site to the solution and scored multi-site tasks with pooled AUROC; the loop used them
(\cref{sec:shortcuts}). All other results use v2: no demographics or motion; site, study and
batch only for harmonization; multi-site tasks scored \emph{within site} (size-weighted mean of
per-site AUROCs); and TDBRAIN tasks restricted to the age range shared by patients and controls.
v2 was designed after we saw v1 results, and the v2 loops were rerun on the same split seeds; this
and other post-hoc decisions are listed in \cref{app:disclosures}.

\paragraph{Evaluation.} For each split seed (1, 2, 3), 25\% of subjects (grouped by subject;
stratified by label and site) form a held-out \emph{Eval} set and the rest a \emph{dev pool}. The
loop optimizes \emph{Dev}, a 5-fold grouped CV score inside the dev pool. After the loop, seed and
champion are refit on the whole dev pool and scored \emph{once} on Eval and on external datasets.
The three Eval sets overlap, so splits are not independent replicates. On 9 tasks, split 1 was
rerun twice more from scratch (only the LLM's sampling differs) to measure run-to-run variation.

\paragraph{Same-budget baselines.} All arms start from the same seed, use the same harness, time
limit and 20 Dev evaluations, keep a candidate only if it beats the seed on Dev, and are scored once
on the same Eval sets. \emph{One-shot}: one LLM proposal. \emph{Best-of-20}: 20 independent LLM
proposals that see the briefs and the seed but no history or scores, isolating the value of feedback.
\emph{Optuna}: 20 trials of multivariate TPE over a hand-written parameterized pipeline per project
(which feature blocks to include, which classifier, its regularization). The search spaces were
written \emph{after} the main study and include feature families the loop had found, so this
baseline is informed by the loop's results: stronger than an independent search, and conservative
from the loop's point of view. Arms are equalized in Dev evaluations, not in compute or LLM tokens.

\paragraph{Statistics.} Per task, the gain is the mean over three splits. We report three two-sided
$p$-values (2{,}000 bootstrap draws, $(k+1)/(n+1)$ convention \citep{davison1997bootstrap}, Holm-adjusted
across 12 tasks \citep{holm1979}): a \emph{subject} bootstrap that resamples subjects and treats the
fitted models as fixed; a \emph{hierarchical} bootstrap that resamples splits, then loop runs where
repeats exist, then subjects; and a $t$-test across the three split gains. Per-task claims use the
hierarchical $p$. With only three splits its split level is coarse: when all three split gains have
the same sign, resampling splits cannot produce a mean of the opposite sign, so the hierarchical $p$
then largely reflects sign consistency plus subject noise. We therefore also report sign agreement
across independent repeats. Pooled over the 11 AUROC tasks we report the equal-weight mean of task
gains with a $t$-interval (primary) and DerSimonian--Laird random effects \citep{dersimonian1986}
(secondary), with leave-one-task-out and confound-based sensitivity analyses. Details of the
shortcut-only models, the confound analysis and the transduction and leakage audits are in
\cref{app:methods}.

\section{Results}\label{sec:results}
% ===========================================================================================

\subsection{Development gains are guaranteed; held-out gains are not}\label{sec:dev-eval}
Across 36 runs the loop ran 710 rounds and kept 281 candidates (7 failed rounds). Dev improved in
36/36 runs, as the keep-if-better rule guarantees; Eval improved in 25/36, with per-split
$p<0.05$ in 15/36 (\cref{tab:main-app}). The mean Dev gain (0.075) exceeded the mean Eval gain
(0.047) and the two were only moderately correlated ($r=0.37$; \cref{fig:dev-eval}). CRC, plasma AD,
ABIDE autism and IBD lost or stayed flat on Eval in at least two of three splits despite consistent
Dev gains (\cref{tab:combined}).

\subsection{Feedback, not the LLM alone, produces the gains}\label{sec:baselines-results}
\Cref{tab:combined} and \cref{fig:baselines} compare the loop with the baselines. One LLM proposal
was kept in 17/36 splits and changed Eval by $+0.004$ on average. Twenty proposals without feedback
did better ($+0.014$) but were kept in only 25/36 splits: on neonatal seizure detection and ADHD
(TDBRAIN), none of 120 independent proposals beat the seed on Dev, while the loop improved every
split of both tasks. The loop's own first two rounds on neonatal seizures also failed in every split,
and its first kept change came in round 3. All 720 best-of-20 proposals ran, so low adoption
reflects proposal quality, not a broken baseline.

The loop-informed Optuna search gained $+0.033$ on average ($p=0.073$). It matched the loop on both
TDBRAIN tasks (MDD 0.946 vs.\ 0.954; ADHD 0.918 vs.\ 0.922) and on ADHD-200 (0.650 vs.\ 0.665), and
beat it on plasma and CSF AD; on IBD a single LLM proposal did best. The loop's advantage over
Optuna was Holm-significant only on abnormal EEG ($+0.029$) and neonatal seizure detection
($+0.075$).

\subsection{Per-task and pooled statistics}\label{sec:stats-results}
With the hierarchical bootstrap, the loop's gain over the seed is Holm-significant on four tasks:
abnormal EEG ($+0.071$), MDD ($+0.104$) and ADHD ($+0.137$) on TDBRAIN, and neonatal seizure
detection ($+0.072$) (\cref{tab:combined}). The CRC loss ($-0.055$) and the ADHD-200 gain ($+0.093$)
are significant only conditionally on the fitted models; the ADHD-200 gain rests on one split. The
caveat in \cref{sec:methods} applies to the four significant tasks: their three split gains all
have the same sign, and the $t$-test across splits, which does not have that problem but has little
power, gives $p=0.021$ (abnormal EEG), $0.028$ (neonatal seizure), $0.053$ (MDD) and $0.13$ (ADHD on
TDBRAIN). Independent repeats are the stronger evidence. On abnormal EEG, neonatal seizure detection
and MDD, all five independent loops (three on split 1, one each on splits 2 and 3) improved on the
seed (abnormal EEG $+0.054$ to $+0.091$; neonatal seizure $+0.048$ to $+0.087$; MDD $+0.057$ to
$+0.141$). ADHD on TDBRAIN has no repeats.

Pooled over 11 AUROC tasks (\cref{tab:pooled}), the loop gained $+0.050$ over the seed
($p=0.029$; $I^2=85\%$), $+0.036$ over best-of-20 ($p=0.063$) and $+0.017$ over Optuna ($p=0.28$).
The gain over the seed is fragile: leaving out any one of six tasks (ADHD-200, MDD, ADHD on TDBRAIN,
schizophrenia, abnormal EEG or neonatal seizure) gives $p=0.054$--$0.064$; counting the two TDBRAIN
tasks, which share controls, as one dataset gives $+0.043$ ($p=0.062$); and leaving out TDBRAIN and
ADHD-200 gives $+0.027$ ($p=0.25$). The loop's advantage over Optuna stays at $+0.017$ to $+0.021$
and non-significant in every variant.

\subsection{Shortcuts and demographic confounds}\label{sec:shortcuts}
Under protocol v1, every ADHD-200, ABIDE and pooled-IBD champion referenced non-biological inputs:
site, age and sex (ADHD-200); site, age, sex and head motion (ABIDE); study identity (IBD). These
inputs carry substantial signal alone (\cref{fig:shortcuts}): site plus age and sex reach a pooled
Eval AUROC of 0.775 on ADHD-200, close to the v1 champion (0.813), and study identity alone gives
0.693 on IBD. Rescored within site, the v1 ADHD-200 champion drops from 0.813 to 0.731, close to
the v2 champion (0.717).

Within-site scoring removes the site shortcut but not demographic signal, which brain data encode
even when age and sex are not given as inputs. We therefore tested whether age and sex explain the
v2 predictions (\cref{tab:confounds}, \cref{fig:confounds}). On ADHD-200, age and sex alone reach a
within-site AUROC of 0.645, close to the champion's 0.665; adjusting for them lowers the champion to
0.621 (seed 0.545), and the prediction adds significant information beyond age and sex in only one
of three splits. On ABIDE and both TDBRAIN tasks, age and sex alone are at chance (0.45--0.51) and
adjustment changes the AUROC by at most 0.021; the loop's MDD gain shrinks from $+0.104$ to $+0.076$
after adjustment and its ADHD (TDBRAIN) gain is unchanged ($+0.140$). Age and sex therefore do not
explain the TDBRAIN results, but they cannot rule out other differences between separately recruited
patients and controls (\cref{sec:transfer}). ASEEG and our TUAB build carry no demographics.

\subsection{In-distribution gains did not transfer to other cohorts}\label{sec:transfer}
Applied unchanged to external data (\cref{fig:transfer}, \cref{tab:external}), the TDBRAIN depression
seed was \emph{inverted} on the Mumtaz cohort (AUROC 0.25--0.29), and the champions were below or
indistinguishable from chance in all three splits (0.28--0.62). The numerical gain moves an inverted
model towards chance; it is not evidence of a transferable marker. The schizophrenia champion was
worse than the seed on the MSU cohort in all three splits (0.696 $\to$ 0.538) and above chance in
only one; on the small RepOD cohort neither seed nor champion was distinguishable from chance. The
CRC champion stayed above chance on the four external cohorts in 11 of 12 split--cohort pairs, but
beat the seed in only 2 of 12. Only abnormal EEG improved on its additional test set (AUROC 0.867
$\to$ 0.928, all CIs excluding chance), and that set is the official TUAB evaluation split from the
same hospital and protocol: a within-hospital check, not transfer. Acquisition differences (amplifier,
montage, recording length, age range) are an alternative explanation to biology for every failure to
transfer.

\subsection{Variance, transduction and leakage}\label{sec:variance}
Repeating the loop on the same split varied the Eval gain less than drawing a new split (run-to-run
SD 0.005--0.044, median 0.017; split-to-split median 0.042; smaller for 8 of 9 tasks;
\cref{fig:variance}). The sign was stable across repeats on abnormal EEG, neonatal seizure, MDD and
schizophrenia (all positive), negative on IBD in all three repeats, and flipped on CRC, CSF AD and
drug response. All seeds were exactly inductive. Scoring Eval inside a reference batch built from
the dev pool changed champion scores by $-0.0006$ on average (worst $-0.024$), so reported scores do
not exploit Eval-set statistics (\cref{fig:audit}); 11 champions output batch-relative ranks and would
need a reference cohort to score single patients. Finally, every champion was rescored in
network-isolated containers with subject identifiers replaced by order-preserving tokens; all scores
were reproduced to within $4\times10^{-4}$, whereas a positive-control solution that read labels from
identifiers dropped from AUROC 1.000 to 0.500. A static scan of all 2{,}010 saved solution files found
no access to files, network or harness beyond the resources a task provides (\cref{app:methods}).

\section{Discussion}\label{sec:discussion}
% ===========================================================================================
\paragraph{When the loop helped.} The clearest gains came on abnormal EEG and neonatal seizure
detection: signal-processing tasks with large or well-annotated data and clinically meaningful
labels. They were the only tasks where the loop beat a loop-informed Optuna search, the gains
replicated in all five independent loops, and independent LLM proposals almost never beat the seed.
The active ingredient is feedback, not the LLM's prior knowledge alone.

\paragraph{When it did not.} Elsewhere the loop was not reliably better than ordinary search, and on
four tasks it lost or stayed flat on held-out data in most splits despite consistent Dev gains. Its
largest in-distribution gains, on TDBRAIN, were matched by Optuna, are not explained by age or sex,
and did not transfer, which points to dataset-specific signal that any optimizer would find. Given
site and demographics, the loop used them. A held-out set scored once, a non-LLM baseline,
shortcut-only and confound models, and an external cohort each changed our reading of at least one
task; the Dev curve alone would have changed none. Where a rough comparison with published results is
possible, the champions were not better (Helsinki 0.899 vs.\ about 0.955 \citep{tapani2022}; on CRC
the seed already matched the MicrobiomeHD baseline \citep{duvallet2017}).

\paragraph{Limitations.} Several Eval sets are small (20--43 subjects), the three splits overlap, and
with three splits per-task inference across splits is weak; repeats cover 9 of 12 tasks. The v2
protocol, the IBD task definition and the Optuna search spaces were fixed after Eval results had been
seen, and no confirmation on fresh splits with a pre-registered analysis was run. We used one LLM at
one setting and a CPU budget that favours light models, and three early loops used an earlier brief
wording. TDBRAIN cases and controls were recorded separately. Further caveats are in
\cref{app:caveats,app:disclosures}.

\section{Conclusion}\label{sec:conclusion}
An LLM autoresearch loop with feedback improved held-out performance over a simple seed on most of
12 biomedical tasks, clearly more than the same LLM without feedback, but significantly more than a
loop-informed non-LLM search on only two signal-processing tasks, where its gains also replicated
across independent runs. The same loop exploited site and demographic shortcuts when allowed, and its
psychiatric-EEG gains did not transfer. Gains from such a loop are a hypothesis to test on held-out,
shortcut-free and external data, not evidence of a better biomarker.

\section{Additional methods}\label{app:methods}
\paragraph{Prompt and rules.} The brief asks for one well-motivated change per round, forbids reading
anything outside what the harness passes in, requires inner CV (grouped by subject) for any tuning
and lists the available libraries (numpy, scipy, scikit-learn, LightGBM, XGBoost, CatBoost, MNE,
pyRiemann, nilearn, PyTorch on CPU, among others). Candidates run on Modal containers with 2--16
cores depending on the task.

\paragraph{Shortcut-only models.} On the four multi-site tasks, L2 logistic regressions using only site
or study one-hot codes and/or demographics were fit on the dev pool and scored on Eval with both
the pooled (v1) and within-site (v2) metric.

\paragraph{Age/sex confounds.} For tasks with per-subject age and sex (ADHD-200, ABIDE, TDBRAIN MDD and
ADHD), we report the Eval AUROC of a model using age and sex only (fit on the dev pool); the AUROC of
the seed or champion prediction after adjusting for age and sex (and site); whether the prediction
tracks age or sex within controls; and a likelihood-ratio test of whether the prediction adds
information about the label beyond age, sex and site.

\paragraph{Transduction audit.} The Eval protocol featurizes dev-pool and Eval items in one call and
passes the whole Eval batch to \texttt{fit\_predict}. For every seed and champion we tested (i)
whether dev-pool features change when Eval items are featurized with them; (ii) a \emph{chunked}
score, with Eval split into 20 chunks (10 for large tasks), each featurized with the dev pool and
predicted on its own; and (iii) a \emph{reference-batch} score, as (ii) but each chunk predicted
inside a batch of dev pool plus chunk, so batch statistics come from training-time data.

\paragraph{Leakage audit.} The loops' candidates were scored in containers that had network access and
the data volume (including labels) mounted, and some datasets encode the label in subject identifiers.
We therefore (i) rescored every champion, and the seeds of tasks whose identifiers encode the label,
in network-isolated containers with real identifiers, with identifiers replaced by order-preserving
tokens, and with random tokens; (ii) ran positive controls (a solution that reads the label from the
identifier; a network probe); and (iii) statically scanned all 2{,}010 saved solution files for file,
network, subprocess and harness access. Random tokens change scores by up to 0.034 on Eval because
they change the assignment of subjects to inner-CV folds; order-preserving tokens reproduce every
score. Rejected candidates of the 36 main loops were not saved and are covered only through their
champions.

\paragraph{Pooled statistics.} Drug response (Pearson $r$) is excluded from pooling. For random
effects, task standard errors are floored at 0.005. Benjamini--Hochberg adjusted values
\citep{benjamini1995} and leave-one-task-out estimates for every comparison are in the released files.

\section{Disclosures}\label{app:disclosures}
\paragraph{Decisions made after Eval results had been seen.} (i) The single-study IBD task (16 stool
controls) was replaced by a pooled four-study task. (ii) Protocol v2 was introduced after v1 Eval
results and v1 champion code had been seen; v2 loops were rerun on the same split seeds. (iii) Two
Mumtaz subjects without eyes-closed data were excluded. (iv) The Optuna search spaces were written
after all loop results. (v) The equal-weight pooled mean was made primary after DerSimonian--Laird gave
infinite weight to arms identical to the seed. (vi) A leakage in the pooled IBD task (biopsies and
repeated samples of one person or co-twin could fall in both Dev and Eval) was found by our audit; the
task was redefined as stool only, grouped by person or twin pair, and all IBD runs were redone. Every
change that altered a task reran that task's loops from scratch.

\paragraph{Unequal conditions.} The main loops of CRC, plasma AD and drug response started before
protocol v2 and used the v1 wording of the brief (these tasks provide no demographics either way);
their split-1 gains differ from the two v2-worded repeats by no more than run-to-run variation on
other tasks. Claude Code CLI versions 2.1.287--2.1.296 were used; model and effort were identical.
Two ABIDE loops stopped early (19 and 11 rounds).

\paragraph{Data-level choices.} The 200 drugs were selected by variance across all cell lines,
including later Eval lines. Proteomics intensities are as released, normalized across all samples by
the original pipelines. Helsinki smoothing windows are centred (non-causal), acceptable offline but not
for online detection. Subject identifiers that encode the label were visible to solutions; no solution
read them (\cref{app:methods}). The seeds were written with an LLM coding assistant before any loop
ran.

\section{Dataset caveats}\label{app:caveats}
\begin{itemize}
  \item \textbf{TDBRAIN.} All controls are adults, so tasks are age-matched to the shared range (ADHD:
        adults only); age is never given to the model. Patients and controls were recruited and
        recorded separately, so state or protocol differences cannot be excluded.
  \item \textbf{ASEEG.} The channel order is undocumented and was inferred from data
        (its correlation structure matches labelled RepOD recordings: $r=0.855$ for the
        standard 10--20 order, $r<0.1$ for the alternatives). MSU is adolescents with 1-min, 16-channel recordings.
  \item \textbf{TUAB.} First 60\,s skipped, next 5\,min used, 19 channels at 100\,Hz, clipped at
        $\pm$800\,$\mu$V \citep{gemein2020}.
  \item \textbf{Helsinki.} Label = majority of three experts per second; published results often use
        leave-one-out or other annotation rules \citep{tapani2022,hogan2025}.
  \item \textbf{ABIDE / ADHD-200.} Within-site AUROC is stricter than the pooled metrics usually
        reported \citep{abraham2017,heinsfeld2018}.
  \item \textbf{IBD.} Four MicrobiomeHD studies, stool samples only, grouped by person (by twin pair in
        the twin study); several people contribute more than one sample.
  \item \textbf{Proteomics.} Plasma: single centre, the only open labelled AD plasma MS set we found.
        CSF label = clinical diagnosis.
  \item \textbf{Drug response.} 200 most variable drugs ($\geq$70\% coverage) from the PRISM
        secondary screen; per-drug Pearson $r$ on held-out cell lines.
\end{itemize}
